# Telegram 设置任务模板

将 `<…>` 替换成用户已确认的选择。真实 Bot 用户名、群名、身份和凭据保存在部署者私有记录中，不能把填写后的模板提交到通用仓库。

为 `<显示名>` 创建新 Bot，并加入 `<目标群>`。用浏览器自动化工具（例如 ego-browser 或 Playwright）或手动完成设置。

1. 打开 `https://web.telegram.org/a/`，使用用户已授权的账户；需要认证时交给用户本人完成。
2. 在 @BotFather 执行 `/newbot`，填写显示名与可用用户名（以 bot 结尾）。
3. **先** `/setprivacy` → Disable，确认 `/setjoingroups` 允许加入群。
4. token 直接存入你的密钥仓库。禁止打印、截图、日志、命令回显、Git 和群消息中出现 token；确认密钥仓库 CLI 的输出不会泄露值片段。
5. 调 `getMe` 确认 `can_read_all_group_messages` 是 true。
6. 将 Bot 加入用户指定的目标群，不授予管理员权限。先加群才关闭隐私模式时，移出并重新加入。
7. 需要私信任务时，由接收者先对 Bot 发送 `/start`。
8. **网关启动前**调用 `getUpdates`，从加群事件和 `/start` 事件获得目标群及 owner 身份，私下填入实例 `.env` 与你的密钥仓库。不要带 offset 消费这些更新，不修改 webhook。
9. 只在私有 brief 记录完成情况。通用仓库不写真实 token、任何数字身份、用户名、群名或密钥仓库的 key 名。

网关启动后，不再调用 `getUpdates`。只操作用户指定的 Bot 管理、Bot 私聊和目标群；其他对话不读取、不发送。对外发送和入群操作应有用户授权。截图必须避开凭据区域，私有证据不进入通用仓库。
